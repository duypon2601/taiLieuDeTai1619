Một câu hỏi đi qua hệ thống

Ví dụ demo S1: “So sánh doanh số các phân khu Ocean Park 2 quý 3/2026”, đăng nhập bằng Builder Miền Bắc.

  1. Frontend

    Builder đăng nhập, nhận JWT mang vai trò và vùng Miền Bắc.

    POST /auth/login
  2. Frontend → Backend

    Gõ câu hỏi ở Studio. Backend kiểm token, ghi audit rồi mở luồng SSE.

    POST /chat/stream
  3. AI

    Guardrail cho qua. LLM hiểu: Ocean Park 2, doanh số, theo phân khu, Q3/2026.

    guard_input → route_intent → extract_entities
  4. AI

    Kiểm quyền: Ocean Park 2 thuộc Miền Bắc, hợp lệ. Hỏi Miền Nam thì bị từ chối.

    check_access
  5. AI → Data

    LLM sinh 4 truy vấn Cube. Cube dry-run để kiểm tra, sau đó lấy dữ liệu và tự lọc theo vùng.

    build_cube_queries → validate → load_data
  6. AI

    Luật R1–R10 chọn KPI, cột theo tháng, donut tỷ trọng phân khu, thanh ngang top sàn.

    advise_charts
  7. AI

    Code tính con số, LLM viết nhận xét bằng placeholder, code điền số thật vào.

    compute_facts → write → verify
  8. Backend → Frontend

    Graph dừng chờ duyệt. Bản nháp v1 lưu vào Postgres, UI hiện dashboard.

    hitl_review · draft_ready
  9. Frontend → Backend

    Builder bấm Duyệt: xuất bản, ghi audit, Viewer Miền Bắc thấy trong thư viện. Muốn sửa thì chat tiếp, tạo ra v2.

    POST /dashboards/{id}/review
